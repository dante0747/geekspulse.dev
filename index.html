FAQ

Frequently asked questions

Still curious? Get in touch or read the privacy policy.

What is GeeksPulse?

GeeksPulse is a free, independent developer news aggregator. It collects the latest articles from 50+ hand-picked RSS feeds into one fast, distraction-free feed covering AI and machine learning, cybersecurity, DevOps, JavaScript, Python, Rust, Go, Java, open source and software architecture — with no ads and no paywalls.

Which programming and development topics does GeeksPulse cover?

Eleven topics: general tech news for developers (Hacker News, Lobsters, Ars Technica, IEEE Spectrum), AI and machine learning (MIT AI News, Google AI Blog, The Gradient), cybersecurity (Bleeping Computer, Krebs on Security, The Hacker News), DevOps and cloud (Docker, Kubernetes, HashiCorp, AWS DevOps), JavaScript and TypeScript (JavaScript Weekly, Node Weekly, MDN Blog), Python (Planet Python, Real Python), Rust (Rust Blog, This Week in Rust), Go (Go Blog, Go Weekly, Dave Cheney), Java and the JVM (Spring Blog, InfoQ Java), open source and Linux (LWN.net, GitHub Blog) and software architecture (Martin Fowler, Netflix Tech Blog, Cloudflare Blog, High Scalability).

Is GeeksPulse free to use?

Yes. GeeksPulse is completely free, with no ads, no paywalls and no sign-up. It is an open-source project built and maintained by a solo developer and supported by optional donations.

How often is the developer news feed updated?

The feed is rebuilt automatically every hour from every curated source. You can also refresh it with the Refresh button or the R key, or turn on auto-refresh in Settings.

Can I filter developer news by programming language or topic?

Yes. Filter by topic, search by keyword, or open a single source. My Pulse lets you hide topics, mute sources, hide sponsored posts and limit article age. Bookmarks, light and dark themes and keyboard shortcuts are built in.

Does GeeksPulse cover cybersecurity and software vulnerabilities?

Yes. The Security topic aggregates Bleeping Computer, The Hacker News, Krebs on Security, Schneier on Security and the SANS Internet Storm Center — covering CVEs, zero-days, data breaches, ransomware, malware analysis and security best practices.

Does GeeksPulse track me or require an account?

No account is needed. Bookmarks and preferences are stored only in your browser and never leave your device. Google Analytics loads only if you accept it in the consent banner.

Does GeeksPulse have a JSON feed or API?

Yes. The aggregated feed is published as machine-readable JSON at https://geekspulse.dev/public/feed.json, and the source code is open on GitHub at github.com/dante0747/geekspulse.dev.
